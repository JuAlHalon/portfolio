Web App Development

Room Reservation API

An API for a room reservation app. This project only contains the API. The purpose of this project was to practice and showcase the use of AI in software development. The initial code for this app was generated with AI. After this I refactored the AI generated code, also with the help of an AI agent. This work was created as part of a job application.

Hakaniemi Market Hall Electricity

An app that displays Hakaniemi market hall's monthly electricity spending for the year 2019. The data is fetched from an external API to an Express server, from where it's requested by an Angular client app. This project taught me more about creating server apps, and about communication between the server and client side apps, Unit tests were also created for the server app. This work was created as part of a job application.

Crypto Analyzer

A crypto currency analyzer created using Angular, where the user can input start and end dates and the app will fetch data from CoinGecko's API and analyze it. This project taught me about fetching and parsing data from an external API. I also got a bit of practice on making unit tests for the application. This work was created as part of a job application.

Find a Coach App

A Vue application where the user can find and contact coaches. It also supports logging in and registering as a coach. This app was created as the main project of a Vue course and was done following the course teacher's instructions. While this project was created alongside the teacher, I have included it in my portfolio as a showcase of the Vue skills I have learned.

Registration App

An Angular application where the user can log in and create a registration for a party. Utilizes an auth-guard to prevent access to the registration form unless the user is logged in. This app was created as part of a Web app development course.

Student Database

An Express REST API backend app that can add, delete, find and update students and their grades in a mongoDB database. Uses JWT token based authentication. This app was created as part of a Web app development course.
